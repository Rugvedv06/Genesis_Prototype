## WP5.0 VERIFY findings

Reviewed 2026-10-17 against current official Google documentation:

1. **Function calling.** Tool declarations are sent in `tools[].functionDeclarations`; optional mode is configured through `toolConfig.functionCallingConfig` (`AUTO`, `ANY`, `NONE`, `VALIDATED`). Model calls are `functionCall` parts. Preserve the returned model content, then append a user `functionResponse` part with call id, name and response. System prompt belongs in `systemInstruction`. [Function calling guide](https://ai.google.dev/gemini-api/docs/generate-content/function-calling), [GenerateContent API](https://ai.google.dev/api/generate-content).
2. **Function schema.** `FunctionDeclaration.parameters` supports the documented Gemini `Schema` fields: `type`, `format`, `title`, `description`, `nullable`, `enum`, `maxItems`, `minItems`, `properties`, `required`, `minProperties`, `maxProperties`, `minLength`, `maxLength`, `pattern`, `example`, `anyOf`, `propertyOrdering`, `default`, `items`, `minimum`, `maximum`. Convert through this allowlist; retain Ajv validation in the application. [Schema API reference](https://ai.google.dev/api/generate-content#Schema).
3. **Usage and billing.** Metadata includes `promptTokenCount`, `candidatesTokenCount`, `totalTokenCount`, `toolUsePromptTokenCount`, `thoughtsTokenCount`, cached counts and modality details. Thinking is a separate count; Gemini 2.5 response billing includes output and thinking tokens. Normalize without double counting. [UsageMetadata](https://ai.google.dev/api/generate-content#UsageMetadata), [thinking and pricing](https://ai.google.dev/gemini-api/docs/generate-content/thinking).
4. **Thinking control.** `gemini-2.5-flash` permits disabling thinking with `thinkingConfig.thinkingBudget: 0`. [Thinking configuration](https://ai.google.dev/gemini-api/docs/generate-content/thinking).
5. **Structured output.** REST uses `generationConfig.responseFormat.text.mimeType` as the enum `APPLICATION_JSON`, with `.schema`; the SDK's JavaScript surface may accept `application/json` and translate it. Always validate with Ajv. Live REST returned an invalid-enum error for `application/json`, so the shared REST provider sends `APPLICATION_JSON`. [GenerateContent API](https://ai.google.dev/api/generate-content), [Structured output](https://ai.google.dev/gemini-api/docs/generate-content/structured-output).
6. **Quota and rotation.** Gemini rate limits are applied per Google Cloud project, not per API key. Four keys associated with the same project do not create four times the quota. [Rate limits](https://ai.google.dev/gemini-api/docs/rate-limits), [API key guidance](https://ai.google.dev/gemini-api/docs/api-key).
7. **Function names.** Gemini documents function name length up to 128 characters and a restricted ASCII character set. Application-facing tool names retain the plan's conservative regex `^[a-zA-Z][a-zA-Z0-9_]{0,63}$`, which stays within the documented limit. [FunctionDeclaration](https://ai.google.dev/api/generate-content#FunctionDeclaration), [FunctionCall](https://ai.google.dev/api/generate-content#FunctionCall).
8. **Key authentication.** REST accepts `x-goog-api-key`; keys can be sent in headers rather than query strings. [Structured output REST example](https://ai.google.dev/gemini-api/docs/generate-content/structured-output).
9. **429 behavior.** Official troubleshooting recommends exponential backoff for 429/503. Do not retry the same 429 against every key because project quota is shared. Respect a valid `Retry-After` only if returned and within the caller's remaining budget. [Troubleshooting](https://ai.google.dev/gemini-api/docs/troubleshooting).
